# 技能仓库管理

[English](03-repository-guide.en.md)

更新时间：2026-09-21 07:19（Asia/Shanghai）

## 使用方式

页面统一采用「标题说明 → 页签 → 当前页签操作按钮 → 筛选与列表」的顺序，与归档会话页一致。

设置 → 技能 → 技能仓库，选择「添加仓库」。输入 `owner/repo` 或公开 GitHub 仓库地址，可填写分支或标签、技能子目录。留空分支时使用远端默认分支；留空子目录时扫描整个仓库。

地址可以包含 `tree/分支/子目录`。分支本身含斜杠时，请填写仓库根地址，并把完整分支放进独立字段。不接受访问令牌、查询参数、其他域名或 HTTP 地址。

添加后立即扫描；失败时来源仍保留，可从「管理仓库」重试刷新。仓库默认折叠，搜索或状态筛选会展开匹配内容。详情展示技能说明、路径及扫描内容快照。

点击「安装」将单个技能连同资源复制到 `$DSH_HOME\skills`。下载和安装不会执行技能脚本。已安装技能可以从全局技能页继续启停或移入回收站。

## 状态含义

| 状态 | 含义与操作 |
|---|---|
| 可安装 | 本地没有同名技能，可以安装。 |
| 已安装 | 存在本仓库安装记录，且记录中的文件哈希与当前全局 DSH 副本一致。 |
| 同名冲突 | 本地已有同名来源，或安装副本已修改；安装按钮禁用，不覆盖本地。 |
| 格式无效 | 缺少完整 frontmatter、合法名称或描述；修复仓库后刷新。 |

刷新只更新来源列表和扫描内容快照，不替换安装副本，也不宣称已安装副本是远端最新版本。移除仓库只取消订阅，安装副本保留；重新添加同一来源时，保留的安装记录仍可用于追溯。

## 限额与失败处理

- 最多 30 个仓库；单仓库最多 500 个技能、技能正文累计约 4 MiB。
- 下载归档最多 32 MiB，展开最多 64 MiB、10000 条记录；单个技能导入继续遵循既有 1000 文件限制。
- 单篇说明最多 256 KiB；路径最多 512 字符、64 层。
- 单次网络请求超时为 60 秒，不跟随重定向；扫描、安装与更新仅访问 `codeload.github.com`。
- GitHub 限流、网络错误或非法归档不会清空上次目录。修复网络或稍后手动刷新即可。
- 来源状态存于 `$DSH_HOME\skills-manager\repositories.json`；文件损坏时拒绝写入，保留原始数据供修复。

首版仅支持公开 GitHub 仓库，不提供自动更新、私有仓库凭证、批量覆盖或项目级安装。

## 来源与在线更新

全局技能名称下展示安装来源：可追溯记录显示 GitHub 仓库链接，其他技能显示本机；现有来源分组仍表示文件存放位置。管理更新可定位仓库中的技能。移除订阅保留来源；继续更新需重新添加同一仓库配置。

在技能仓库点击「刷新并检查更新」，扫描最新版本；比较技能说明、脚本与所有资源的文件哈希。存在差异显示可更新；仓库其他内容变化不误报。此操作更新扫描缓存，不执行安装或替换。

查看更新展示新增、修改、删除文件，确认备份并更新后才替换。检测到本地修改时默认拒绝，必须使用备份本地修改并替换。预览后文件或版本变化会要求重新预览。更新完成保留上一版；恢复上一版也需预览和确认，恢复前会备份当前副本。

备份位于 $DSH_HOME\skills-manager\repository-backups，不自动清理。普通替换或状态写入异常会自动恢复；强制结束进程、断电等中断需人工恢复。上一版包含更新前本地修改，恢复后可能仍显示同名冲突，这是保留修改的预期结果。

## 归档直连与缓存

检查更新直接下载分支ZIP，不调用GitHub REST API，因此不消耗匿名API每小时60次额度。未指定分支使用HEAD，404才尝试main和master；指定分支404时尝试同名标签，不自动切换到其他分支。403或超时立即提示错误。

扫描内容版本是归档SHA-256摘要，不是Git提交号。缓存保存在 $DSH_HOME\skills-manager\repository-cache；安装和更新使用扫描时已校验的归档，避免重复下载和分支移动。缓存缺失或损坏时拒绝继续，需重新检查更新；不静默安装远端新内容。

成功刷新后仅保留同一订阅当前归档；失败保留上次列表和缓存。内容是否可更新仍比较技能全部文件哈希，不因ZIP打包时间或仓库其他文件变化而误报。旧40位提交记录仍能读取，下一次刷新自动生成64位内容快照；插件降级需要相容的状态备份。

## 安装中断恢复

如果文件已安装但来源记录未确认，界面会明确提示状态写入失败。恢复磁盘空间或写入权限后，重新打开技能仓库：仅当完整目录与安装意图中的文件清单和哈希一致时，才自动恢复来源记录并持久化。新增、修改、缺失文件或目录链接均不会被自动认领；保留现有文件供人工检查。

仓库归档超过 32 MiB 会显示专用大小限制提示。子目录筛选发生在整库下载之后，不能减小下载体积。备份不自动清理，界面会提示占用随更新增加；只提供最近一次备份的快捷回退，旧备份保留在上述目录。
